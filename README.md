# Amazon Lightsail Windows Instance

## Practical Work

Topic: Launching, configuring, and connecting
to a Windows instance using Amazon Lightsail.

## Objectives
- Understand Windows virtual instances.
- Learn network security configuration.
- Understand Remote Desktop Protocol (RDP).
- Document the connection procedure.

## Procedure
1. Open Amazon Lightsail.
2. Create a Windows instance.
3. Configure network and firewall rules.
4. Obtain the administrator credentials.
5. Connect using RDP.
6. Verify the Windows desktop.

## Security
- Restrict RDP access to trusted IP addresses.
- Use a strong administrator password.
- Review cloud service costs before deployment.

## Important
This repository documents the procedure.
It does not create a real AWS instance.
