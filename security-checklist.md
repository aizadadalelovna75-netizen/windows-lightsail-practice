# Windows Server Security Checklist

- [ ] Select the correct Windows Server blueprint.
- [ ] Verify the instance plan and cost.
- [ ] Check the instance state.
- [ ] Review firewall rules.
- [ ] Restrict TCP port 3389 to trusted IP addresses.
- [ ] Protect administrator credentials.
- [ ] Test remote desktop access.
- [ ] Verify the Windows desktop.
- [ ] Record screenshots for the report.

## Important

These checkboxes are a planning checklist.
They do not confirm that a real instance has been created.
